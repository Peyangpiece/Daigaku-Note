授業資料を、
回ごとのノートに。

大学の LMS に上がった授業資料を、授業ごと・回ごとのフォルダにそろえ、PDF にそのまま書き込み、資料から作ったクイズで復習できる、大学生のための電子ノートアプリです。

ダウンロード Mac・Windows
経営学入門月 2限
経済原論 II金 3限
統計学水 1限

できること

資料が勝手にそろう

大学のアカウントでつなぐと、新しい資料を自動でダウンロードし、デスクトップの「大学ノート → 学期 → 授業 → 回」のフォルダに入れます。

いま自動でつなげるのは Moodle です（manabo は試験中）。ほかの LMS でも、ファイルをドラッグすれば同じように回ごとに整理できます。

PDF にそのまま書き込む

文字入れ・付箋・ペン・定規、それに赤シートで隠れる「文字隠し」。元のファイルは変えずに書き込みを残し、書き込み付きの PDF にも書き出せます。

回ごとのクイズで復習

その回の資料からクイズを作り、まちがえた問題を間隔をあけて出します。文字隠しにした語からは、AI を使わずに穴埋め問題も作れます。

AI のクイズ作りは、自分の Claude API キーで使います。

学年暦どおりの日付

大学の学年暦（PDF など）から授業回（①〜⑮）と休講日を読み取り、「第○回」の日付と「今日の授業」を大学の予定にそろえます。

自分好みに着せ替え

ノートの紙・フォルダ・マスキングテープ・ファイルの絵・付箋・しおりの見た目を変えられます。シールを貼って、自分だけのノートに。

データは自分のパソコンに

資料と書き込みはパソコンの中に保存します。大学のパスワードは OS の仕組み（Mac はキーチェーン、Windows は DPAPI）で暗号化して、パソコンの外に送りません。

ダウンロード

最新版は GitHub の Releases から配っています。

Mac

Apple シリコン（M1 以降） Intel

はじめて開くときに止められたら、「システム設定 → プライバシーとセキュリティ」の「このまま開く」を押してください（Apple の証明書で署名していないためです）。

Windows

Windows（64 ビット）

「Windows によって PC が保護されました」と出たら、「詳細情報 → 実行」を押してください（Microsoft の証明書で署名していないためです）。

入れたあとは、起動したときと 1 時間ごとに新しい版を確かめて、自動で更新します。

よくある質問

お金はかかりますか？

アプリそのものの料金はありません。クイズを AI で作るときだけ、自分の Claude API キーの利用料がかかります（アプリの中で 1 日・1 か月の上限を決められます）。AI を使わなくても、資料の整理・書き込み・穴埋め問題は使えます。

どの大学で使えますか？

大学は問いません。資料の自動ダウンロードは、いまは Moodle に対応しています（manabo は試験中）。ほかの LMS にも順に対応していきます。それまでは、ダウンロードした資料を授業の画面にドラッグすれば、回ごとに整理して書き込めます。

授業資料をほかの人に送ったりしませんか？

しません。資料を共有・公開する機能はありません。AI でクイズを作るときだけ、その回の資料の本文（学籍番号・メール・電話番号を除いたもの）を Anthropic の Claude API に送ります。送る前に、何を送るかを確かめて同意してもらいます。くわしくはプライバシーポリシーを見てください。

大学の規約で自動ダウンロードが禁止されていたら？

はじめの設定で、自分の大学の規約を確かめたかどうかを聞きます。自動の同期を使わず、手で取り込むだけでも使えます。

「α 版」とは？

正式な公開の前の試しの版です。機能や見た目が変わることがあります。困ったことがあれば、GitHub の Issues で知らせてください。
