プライバシーポリシー

版：2026-11-14（アプリの「設定 → 情報 → 利用規約とプライバシーポリシー」と同じ文章です）

アプリ（パレットノート）が扱うデータ

  1. 保存する場所：授業・回・資料の一覧、書き込み（注釈）、クイズ、設定、ポイントは、このパソコンのアプリ用フォルダ（設定 →「情報」→「データの場所を開く」）に保存します。資料のファイルは、設定した保存先（既定はデスクトップの「パレットノート」）に保存します。iPad のアプリを使うときは、iPad の中（アプリの保存領域）に保存します。開発者のサーバーには送りません。
  2. 大学のアカウント：LMS のパスワード・Cookie・トークンは、OS の鍵（Mac はキーチェーン、Windows は DPAPI）で暗号化して、このパソコンの中だけに保存します。ログ、バックアップ、Google ドライブへ送るデータには入れません。ログインの ID は、次に入れるときのために設定にも残します（バックアップと、Google ドライブへ送るデータに含まれます）。
  3. AI（クイズ）：クイズを作る AI を選んで同意したときだけ、その回の資料の本文（学籍番号などの ID・メール・電話番号は消してから）、授業名、回のタイトル、回のメモ、資料のファイル名を、選んだ AI に送ります（自分の Claude API キーなら Anthropic の API、このパソコンの Claude Code なら Claude Code を通して Anthropic、Codex なら Codex を通して OpenAI）。クイズの答えの画面で質問したときは、その問題と解説、根拠のページと前後のページの本文、自分の答えと質問も送ります。Claude Code・Codex は、本人がそれぞれにログインした契約で動きます。大学のアカウント、資料のファイルそのもの、ほかの回の資料、成績は送りません。API キーは OS の鍵で暗号化して保存します。
  4. Google ドライブ（自分で連携したときだけ）：設定 →「データ」で Google と連携すると、データベース（授業・書き込み・クイズ・設定）、資料のファイル、ノートに貼った写真などを、端末の中で暗号化してから、あなたの Google ドライブの「このアプリだけが使える領域」に置きます。暗号化の鍵は、あなたのパソコンと iPad だけが持ち、Google も開発者も中身を読めません。暗号化されずに Google から見えるのは、ファイルの数・大きさ・更新の時刻と、合言葉を決めたときの記録（決めた時刻・その端末の名前）です。合言葉を決めると、鍵を合言葉で包んだものをドライブに置きます（合言葉そのものは置きません）。短い・ありふれた合言葉は、あなたの Google アカウントに入れた人に破られるおそれがあるので、長く、ほかで使っていないものにしてください。連携した Google アカウントのメールアドレスは、端末の中に保存します。iPad のアプリは、Google のログインの情報と暗号化の鍵を iPad の中に保存します。
  5. スマホ・iPad とつなぐ（自分でオンにしたときだけ）：設定 →「スマホ」でオンにすると、同じ Wi-Fi の中で、パソコンからスマホ・iPad へ資料・書き込み・問題を直接送ります（インターネットや開発者のサーバーは通りません）。やりとりは、つないだ端末ごとの鍵で暗号化します。オンのあいだは、同じ Wi-Fi のほかの端末からもパソコンのこの入口が見えます（鍵がなければ中身は読めません）。
  6. 通信：アプリは、設定した LMS、Anthropic の API（同意したときだけ。Claude Code・Codex を選んだときは、それぞれのコマンドが Anthropic・OpenAI と通信します）、Google（ドライブと連携したときだけ。ログインとドライブ）、同じ Wi-Fi のスマホ・iPad（つないだときだけ）、新しい版の確認と取得のための GitHub、初回の Chromium の取り込みのための Playwright の配布サーバーにだけ通信します。利用状況の収集（テレメトリ）や広告はありません。
  7. ログ：不具合を調べるために、動作の記録を 7 日分このパソコンに残します（パスワードや Cookie は書きません）。LMS の読み取りに失敗したときは、画面の骨組み（文字の多くを伏せたもの）を残します。これらは自動では送らず、本人が報告のために開発者へ送るときだけ使います。
  8. バックアップ：毎日、データベースの写しを 7 日分アプリ用フォルダに残します（大学のアカウントのパスワード・Cookie・トークンは含みません）。
  9. 削除：アプリを消しても、アプリ用フォルダと保存先の資料は残ります。全部消すには、その 2 つのフォルダを消してください。LMS の接続を削除すると、その接続のアカウントの情報も消えます。Google ドライブに置いたデータは、設定 →「データ」の「ドライブのデータを消す」で消えます。iPad のアプリのデータは、アプリを消すと消えます。
  10. 問い合わせ：GitHub の Peyangpiece/Daigaku-Note の Issues で受け付けます。

AI でクイズを作るとき

自分の Claude API キーを登録して同意したときだけ、Anthropic の API に送ります。

送るもの

  • その回の資料の本文（学籍番号などの ID・メール・電話番号は消してから）
  • 授業名、回のタイトル、その回のメモ、資料のファイル名
  • 答えの画面で質問したとき：その問題と解説、根拠のページと前後のページの本文、自分の答えと質問

送らないもの

  • 大学のアカウント・パスワード・Cookie
  • 資料のファイルそのもの、ほかの回の資料、成績、LMS の URL

このホームページ

  • このホームページは、アクセス解析・広告・Cookie を使いません。
  • ページを表示するときに、文字の形（フォント）を Google Fonts から、最新版のファイルの一覧を GitHub から読み込みます。このとき、見ている人の IP アドレスなどがそれぞれのサービスに送られます。
  • このホームページは GitHub Pages で公開し、アプリのファイルは GitHub（Releases）から配っています。GitHub は、そのサービスの決まりに沿ってアクセスの記録を残すことがあります。
