## 公式の文房具の作り直し

`scripts/pens3d/build.py` を Blender の Python で動かす（Blender 本体は要らない）。

```sh
python3 -m venv /tmp/bl && /tmp/bl/bin/pip install bpy==5.2.3   # Python 3.13 が要る
sudo apt install fonts-ipafont-gothic                            # 印字の和文
/tmp/bl/bin/python scripts/pens3d/build.py                       # 5 つの GLB をここへ書き出す
/tmp/bl/bin/python scripts/pens3d/build.py --only pen-ballpoint-wood --preview /tmp/pv   # 1 つだけ・確かめの絵も
```

色は GLB に入れず、アプリが材質の名前（Body・Accent・Grip・Print など）で品ごとに塗る（`src/renderer/model3d-three.js` の `tint`。仕様は SPEC §9.8「3D モデルの見た目」）。
