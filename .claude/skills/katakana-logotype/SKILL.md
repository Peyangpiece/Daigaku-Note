# カタカナのロゴタイプ

市販の書体を打っただけのカタカナは、誰でも同じものが作れて、仮名どうしの大きさや空きもそろわない。
このスキルは、カタカナを 1 字ずつ線で作り、字面と空きを目でそろえて、ロゴとして持てる形に仕上げる手順をまとめたもの。
ロゴ全体の進め方（概念・小さいサイズの確認・書き出し）は logo-design スキル（kaankiziltug/logo-design-skill）に従い、ここではカタカナに固有のことだけを扱う。

参考にしたもの（取得して読んだもの）

- kzhrknt/awesome-design-md-jp（MIT）：仮名の詰め（palt のようなプロポーショナルな詰め）、小振りな仮名は上品に見えること、詰めると濁点まわりの空きが不ぞろいになりやすいこと、長いカタカナ語の切れ目
- heydavidf/typography（MIT）：見出しの文字は詰めてよいが実寸で確かめる、1 回に 1 つだけ変えて比べる、黒地と白地で濃さを比べる
- kaankiziltug/logo-design-skill（MIT）：横画を細くする、オーバーシュート、反転したら細らせる、16 px での確認、`<text>` を残さない

## 1. 仮想ボディと字面を決める

- 1 字の枠（仮想ボディ）を正方形で決め、その中で実際に字が占める範囲（字面）を決める。カタカナは漢字より字面が小さく作られるが、カタカナだけのロゴでは字面を大きめ（ボディの 85〜95 %）にすると、現代的で親しみやすく見える。小さめ（小振り）にすると上品で落ち着く。どちらを選ぶかをはじめに決め、全字に通す。
- 横組みのカタカナは、ベースラインではなく**中心線**でそろえて見る。ト・ノ・レのように細い字、ーのように横に長い字が混じるので、外形の高さではなく、字の重心が同じ高さに並ぶようにする。
- 線の端（丸める・切る・払う）、線の太さ、曲がりの半径の決まりを 1 つに決めて全字に通す。

## 2. 字の形

- **ふところ**（字の内側の空き）を広く取ると明るく親しみやすく、狭くすると締まって古風に見える。ブランドの性格に合わせて全字でそろえる。
- **横画は縦画より 5〜10 % 細く**する（同じ太さだと横画が太く見える）。長音符「ー」も横画として細くする。斜めの画は交わるところで細くして、黒くたまらないようにする。
- **払い**（ノ・ソ・ツ・パの左の画など）は、まっすぐな線にせず、終わりに向けて方向が変わる曲線にする。始まりの角度を字どうしでそろえる。
- 同じ字が 2 回出る（パレットノートの「ト」など）ときは、まったく同じ形にする。字どうしの似た部分（トの点とソの点、ノとパの払い）も角度をそろえる。
- 丸い部分と尖った部分は、まっすぐな部分より 1〜3 % はみ出させる（オーバーシュート）。

## 3. 小さい仮名・長音・濁点

- **促音・拗音（ッ・ャ・ュ・ョ・ァ など）**は、普通の字の 70〜80 % の大きさにする。横組みでは下に寄せ（下端を普通の字の字面の下端にそろえる）、左右の空きを詰める。線の太さは縮めずに、普通の字とほぼ同じにする（縮めると細く弱く見える）。
- **長音符「ー」**は、字面の中心線の高さに置く。長さは前後の字の字面の幅に近づける。短すぎると「一」や「-」に見え、長すぎると間延びする。
- **濁点・半濁点**は、字の右上の、字面のすぐ外かわずかに重なる位置に置く。半濁点の丸は、主な線より細い線で描き、内側の穴が 16〜24 px でもつぶれない大きさにする。詰めたときに、濁点のある字の右の空きが広く見えやすいので、次の字との空きは濁点を除いた字の形で見て決める。
- 濁点・半濁点は色を変えやすい場所でもある。色を変えるなら、1 色の版でも字として読めることを先に確かめる。

## 4. 詰め（字間）

- 等幅（ベタ組み）にしない。**字と字のあいだの空きの面積**が同じに見えるように 1 組ずつ決める（プロポーショナルな詰め）。
- 片側が開いた字（ト・レ・ノ・ッ・ー の端）は、その側の空きを詰める。縦の線どうしが向き合う組（トの縦画とノの払いの始まりなど）は離す。
- 仕上げに、全体を少し縮めた大きさで見て、空きのむらがないかを確かめる。迷ったら、字の輪郭を少しぼかして見る（にじませると空きのむらが分かりやすい）。

## 5. 英字のロゴと並べるとき

- カタカナの字面の高さは、英字の大文字の高さの 1.0〜1.15 倍にすると同じ大きさに見える。
- 線の太さは、見た目で同じに見えるようにそろえる（カタカナは画が少ないので、同じ数値だと軽く見えることがある）。
- 端の形・曲がりの半径・アクセントの色の使い方を共通にする（例：英字の O と、カタカナの半濁点を同じアクセントの色の輪にする）。

## 6. 手順

1. 字面・中心線・線の太さ・端の形を決め、1 字ずつ線で描く（SVG のパス。`<text>` は使わない）。
2. 黒 1 色で、大きく（幅 900 px）と小さく（高さ 16・24・48 px）並べて見る。
3. 次の順に 1 つずつ直し、そのたびに前の版と並べて見比べる：字の大きさ（中心線と字面）→ 字の形（ふところ・払いの角度）→ 線の太さ（横画を細く）→ 小さい仮名・長音・半濁点 → 詰め。
4. 白地と紺地（反転）で並べる。反転した版は線を 2〜5 % 細くする。
5. 線を塗りの形に変換し（picosvg など）、logo-design スキルの `svg_audit.py` で確かめる。

## 確かめること（仕上げの前に）

- [ ] どの字も、ひと目でその字に読める（パがハやバに、ッがツに、ーが一に見えない）
- [ ] 字の重心が中心線の上にそろっている
- [ ] 横画が縦画より少し細い
- [ ] 小さい仮名が 70〜80 % で、下にそろい、線が細りすぎていない
- [ ] 半濁点の穴が 24 px でつぶれない
- [ ] 字と字の空きが、面積で同じに見える
- [ ] 同じ字が同じ形
- [ ] 黒 1 色・反転・16 px で読める
- [ ] `<text>` が残っていない
