# 大学ノート

大学の LMS に上がった授業資料を、何もしなくても授業ごと・回ごとのフォルダにそろえ、そのまま PDF に書き込んで学び、資料から作ったクイズで回ごとに復習できる、**全国の大学生**のための電子ノートアプリ（Mac・Windows のデスクトップアプリ）。

- 大学アカウントと同期し、新しい資料を自動でダウンロードして、デスクトップの「大学ノート → 学期 → 授業 → 回」フォルダに保存する
- LMS は 4 階層で対応：API 型（Moodle・Canvas）・画面操作型（manaba・WebClass・manabo・Google Classroom・Microsoft Teams …。手順は JSON のレシピ）・汎用型（レシピのない LMS）・手動取り込み。どの大学でも最低限動く
- ホームは罫線ノートの上にマスキングテープで貼った授業フォルダ。ポップでシンプル、余白が主役のデザイン
- アプリ内の PDF ビューアで「文字入れ」「メモ」「文字隠しマーカー」。文字入れのフォントサイズは授業ごとに変えられる
- 回ごとの資料から Claude API でクイズを作り、間隔をあけた復習で定着させる

## 開発

```
npm ci        # 依存を入れる（Electron・Playwright など）
npm test      # node --test（純粋ロジック・DB・ファイル管理・同期エンジン・Moodle コネクタ）
npm start     # Electron で起動
```

Node 22.13 以降（SQLite は `node:sqlite` を使う）。
