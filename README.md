# 大学ノート

大学の LMS（manabo）に上がった授業資料を、何もしなくても授業ごと・回ごとのフォルダにそろえ、そのまま PDF に書き込んで学び、資料から作ったクイズで回ごとに復習できる、大学生のための電子ノートアプリ（Mac・Windows のデスクトップアプリ）。

- 大学アカウントと同期し、新しい資料を自動でダウンロードして、デスクトップの「大学ノート → 学期 → 授業 → 回」フォルダに保存する
- ホームは授業ごとのフォルダのアイコン。授業画面は回ごとの資料一覧
- アプリ内の PDF ビューアで「文字入れ」「メモ」「文字隠しマーカー」。文字入れのフォントサイズは授業ごとに変えられる
- 回ごとの資料から Claude API でクイズを作り、間隔をあけた復習で定着させる
