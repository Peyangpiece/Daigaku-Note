# スキャン用の Palette ノート紙と取り込み

アナログのノート紙（Palette スキャンノート。B5・50 枚組みなど）に書いたものを、アプリの回のノートに取り込む。
写真を貼るのではなく、デジタルの Palette ノートの紙（罫の色・形はデジタルのもの。位置は刷った紙と同じ）の上に、写真から取り出した**書いた線だけ**を、描き直さずにそのまま同じ位置に貼る。紙の汚れ・影・しわ・傾きは残らない。

## 1. 決めたこと

| 項目           | 決め                                                                                                                                                                    |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 紙の大きさ     | B5（182 × 257 mm）。原稿用紙だけ横                                                                                                                                      |
| 罫             | ショップで売っている全形式（`SCAN_FORMAT_IDS`。28 形式）。罫は **ドロップアウトカラー**（薄い水色 `#8fcbea`）で刷る                                                     |
| 罫を引くところ | 高さ 210 mm（セミ B5 のキャンパスノート・A 罫 30 行にそろえる）。上下は同じ幅（23.5 mm）。原稿用紙は上 20 mm・下 18 mm                                                  |
| 目印           | 四隅に黒（`#1a1a1a`）の 5 mm 角。紙の端から 6 mm。右下だけ中に白い四角（向きが分かる）                                                                                  |
| 形式のコード   | 下の端の真ん中。**全ページ同じ**（ページごとに変えない）。23 ビット（区切り 101・形式 6 ビット・版 4 ビット・検査 6 ビット・区切り 1011）。1 ビット 1.5 mm・高さ 3.5 mm |
| 授業・回の欄   | 紙には入れない。送り先は、撮った時刻と時間割から推し量り、スマホで確かめてから送る                                                                                      |
| 上の欄         | 日付の欄（`head: 'date'`）。上の線もドロップアウトカラー                                                                                                                |
| 取り込んだ紙   | デジタルの Palette ノートの罫の色・形（`analogDesign(format)`）。大きさ・罫の位置はスキャン用の紙と同じ。目印とコードは描かない                                         |
| 線の太さ       | 使ったボールペンの太さ（0.3・0.5・0.7 mm）を選ぶ。線の真ん中からその太さ（0.26・0.39・0.53 mm）の半分より外を切る（写真のぼけで太らない。細い線はそのまま）             |

## 2. 刷る紙とアプリの紙は同じ計算

- `shared/notebooks.js` の `scanDesign(format)` が、スキャン用の紙の設定（`size: 'b5'`・`scan: true`・罫の色）を返す
- `pageGeometry` は、`scan` なら四隅の目印と形式のコード（`shared/scan-code.js` の `scanMarks`）も描く
- 刷る紙（`scripts/scan-sheets.mjs`）はこの設定で描く
- 取り込んだときのアプリの紙は `analogDesign(format)`：デジタルの Palette ノートの罫の色（灰色）・形で、B5・`analog: true`（`scanDesign` と同じく原稿用紙の下を 18 mm 空ける）。罫の位置は刷った紙と同じ計算なので、書いた線と罫がずれない。目印とコードは描かない

### 印刷データ

```
node scripts/scan-sheets.mjs [出力フォルダ]   # 既定は dist/scan
```

- `palette-scan-b5-all.pdf`：全形式を 1 ページずつ（試し刷り用）
- `palette-scan-b5-<形式>.pdf`：形式ごと（印刷所に渡し、50 枚に刷る）
- 家庭のプリンターでは「実際のサイズ（100%）」で、B5 の用紙に刷る。横罫は紙の端まで引くので、フチなしでないプリンターでは端が少し欠ける（目印とコードは端から 6 mm 以上内側なので欠けない）

## 3. 取り込みの流れ（v0.20.0）

**入口**

- 回の付箋の「＋ ノート」のメニューの、いちばん下の「アナログノート…」。その回のノートがなければ、最初の紙と同じスキャン用の紙で作る
- ノートを開いた画面のいちばん下（「＋ ページを追加」の並び）の「アナログノート…」。そのノートにページを足す

**取り込みの窓**（`renderer/scan-dialog.js`）

- **読み取るのはスマホのカメラ**（v0.20.2。パソコンのカメラは使わない）。窓のまん中に、スマホのようすを出す
  - スマホがつながっていない（スマホ連携がオフ・つないだスマホがない）：「スマホとつなぐ」。押すとスマホ連携をオンにし、スマホを追加する QR を出す（設定の「スマホを追加」と同じ。10 分・1 回）。QR は https の入口（下の「https」）。QR を読んでつながると、QR を閉じる
  - つながっている：スマホが撮る画面を開いていれば「スマホのカメラを紙に向けてください」「● スマホとつながっています」（2 秒ごとに見る）。開いていなければ「スマホのパレットノートを開いてください」。「QR を出す（スマホをつなぐ）」でいつでもつなぎ直せる
- ファイルを選んで読む方法はない（v0.20.1 で外した）
- 1 枚ごとに読み、読めたページを横に並べる（デジタルの紙に、取り出した線を重ねた見本。外せる）。読めないときは理由をスマホに返す（目印が写っていない・コードが読めない）
- 上に「ボールペン 0.3／0.5／0.7 mm」を選ぶ欄（`localStorage` の `scan.penSize` に覚える。はじめは 0.5）と「かすれと色を整える」
- 「取り込む（n ページ）」で、回のノートにページを足して線を貼り、ノートを開く

**スマホでその場で読む**（`mobile/scan.js`・`shared/scan-live.js`・`main/scan-relay.js`）

- パソコンで「アナログノート…」を押すと、スマホのパレットノートは撮る画面（「アナログノート」）に自分で切り替わる（スマホは開いているあいだ 3 秒ごとに見る。画面が見えているときだけ）。資料・復習の途中では切り替えず、知らせを出す。同じ取り込みでは 1 回だけ切り替える（撮る画面から戻っても連れ戻さない）
- 撮る画面はスマホのカメラ（背面）の映像を出し続け、250 ms ごとに映像を長い辺 720 px に縮めて、四隅の目印（`findMarkers`）と形式のコード（`readCode`）をスマホの中で読む。撮るボタンは押さなくてよい
  - 映像に、見つけた紙の四隅を結んだ枠と、コードから読んだ形式の名前（「横罫 A（7 mm）」など）を重ねる。コードが読めないときは黄色の枠と「もう少し近づけるか、明るいところで」
  - 目印が 4 回続けて（約 1 秒）ほとんど動かなければ（四隅の動きが紙の対角線の 1.2% 未満）、いちばん細かい 1 枚（Android の Chrome は撮る機能 `ImageCapture` でカメラの最大の大きさ、ほかは映像。長い辺 3200 px まで）を JPEG にしてパソコンへ送る（`scan.send`）。止まるのを待つ間は、緑が四隅から伸びる
  - パソコンは窓で読み（Web Worker）、ページを並べ、読めたか（「1 ページ目：横罫 A（7 mm）を読みました」・目印が見えないなど）を返す（60 秒で打ち切り）。読めたら枠が光り、スマホが短く震え、「パソコンに n ページ」を出す
  - 取り込んだ紙は、カメラから外れる（目印が 3 回続けて見えない）まで、もう送らない（同じページを 2 回取らない）。次のページはめくるか、紙を替えて向ける。読めなかったときは、同じ紙をもう一度待つ
  - パソコンが読んでいる間に次の紙が止まったら、読み終えてからその紙をもう一度待って送る（読み終えたときの映像をそのまま送らない。紙が替わっているかもしれないため）
- 取り込む・太さ・整えるかを選ぶのはパソコンの窓で。写真はパソコンに残さない（線を取り出すだけ）
- 撮る画面は 2 秒ごとに、窓が開いた・閉じた・開き直されたかを見る（`scan.waiting` の `watching`。パソコンはこれで「スマホとつながっています」を出す）。窓を閉じると、カメラを止め、送りかけの写真は打ち切る
- **https**（`main/mobile/tls-cert.js`）：スマホのブラウザがカメラの映像を使わせるのは https のページだけなので、スマホ連携は http（47390）に加えて https（47391）でも配る。証明書はこのパソコンで作る自己署名（ECDSA P-256・SHA-256。SAN にパソコンの LAN の番号。825 日）。秘密の鍵は秘密の保管（`secrets.js`）に置く。LAN の番号が変わったら、QR を出すときに作り直す（前の番号も SAN に残す）
  - スマホは初めて開くときに「この接続ではプライバシーが保護されません」などと出す（公の認証局の証明書ではないため）。「詳細を表示」→「このWebサイトを閲覧」（Android は「詳細設定」→「アクセスする」）で進む。窓の QR の下にも書く
  - 前の QR（http）でつないだスマホは、撮る画面で「パソコンの QR を読み直してください」と出す（http のページではカメラを使えない。鍵はページの入口ごとに別に覚えるので、https で開き直すとつなぎ直しになる）

**読み方**（`shared/scan-read.js`。パソコンの中だけで処理する）

1. `findMarkers`：小さくした灰色の画像を、局所の明るさで二値にし、暗いかたまりから四角いもの（縦横比 0.5〜2・詰まり 45% 以上・写真の端にかからない）を選ぶ。いちばん外側の 4 つ（x＋y・x−y の最大・最小）を目印とし、大きさがそろっていることを確かめる。中が明るいものを右下として向きを決める（逆さ・横向きの写真でもよい）
2. `pageTransform`：目印の真ん中（紙の端から 8.5 mm）の 4 点で射影変換を作る。上の辺と左の辺の長さから B5 の縦か横かを決める
3. `readCode`：コードの 23 ビットの真ん中を読み、黒（右下の目印）と白（コードの上の紙）の間で分ける
4. `extractInk`：紙を原寸（12 px/mm）に直し、4 mm ごとの区切りで紙の白さ（明るいほう 90%）を測って割り、影・色むらを消す。緑の暗さ（1 − 緑/紙の緑）が 0.3 を超えるところを線とする（ドロップアウトカラーの水色は緑が明るいので消え、黒・青・赤のインクと鉛筆は残る）。目印・コード・紙のふち 2 mm は取り出さない
   - 線を細線化（Zhang–Suen）して線の真ん中を出し、各画素の「真ん中からの距離」を測る
   - 細線化の前に 3×3 で広げて縮め、小さな抜けを埋める。ひと続きの線ごとに、インクの色の平均（濃いところほど重く）から黒・青・赤・鉛筆を決める。線の中の各画素の「紙からの距離」で、線の太さの半分を測る
   - 線のあたりの画素だけを、写真のままの濃さと色で持つ（白い紙に重ねると写真と同じ色になるよう、白との混ざりを戻す）。字の形は描き直さない
5. `inkImage(ink, 太さ mm)`：真ん中から太さの半分より外を消して画像にする（境目は 1 px でなめらかに）。写真のぼけ・にじみで太って見える分だけを切り、画素は足さないので、細い線は細いまま。太さを変えたときは読み直さずに切り直す
   - `tidy`（取り込みの窓の「かすれと色を整える」。はじめはオン、`scan.tidy` に覚える）：線ごとに決めた 1 色で塗り、線の真ん中から「その線の太さの半分（ボールペンの太さの半分まで）」の中を濃さ 100% にする（かすれを埋める）。字の形と太さは変えない。線の太さより長いとぎれはつながない

**ノートへの足し方**

- `note.addScanPages`：形式ごとにスキャン用の紙のページを足す（上の欄の字は刷らない）。どのページがスキャン用の紙かを `note.scanPages.<id>` に覚え、紙を変える・上の欄を刷り直すときもそのページは B5 のまま描く
- 取り出した線は PNG にして写真として取っておき（`photo.add`）、ページいっぱいの貼りもの（`type: 'photo'`・`scan: true`）として貼る。影を付けず、押しても選ばない（その上にペンで書き足せる）
- アナログノートから作ったノート（`analog`）には、上の欄の授業・回の字を刷らない（紙に書いた日付・題がそのまま写る）

## 4. 進め方

1. 仕様・印刷データ・目印とコードの計算（この版）
2. 取り込みの処理：目印の読み取り・ゆがみ直し・コードの読み取り・色の分離（v0.20.0。作った写真で試験する）
3. アプリへの組み込み：「＋ ノート」と、ノートの画面の「アナログノート…」（v0.20.0）。パソコンで開いた取り込みの窓へ、スマホで撮って送る（v0.20.0）
4. 実物での調整：刷った紙に書いて撮り、ドロップアウトカラーの濃さ（書きやすさと消しやすさ）・目印の大きさ・コードの幅を直す
5. 売る紙の印刷データ（印刷所の入稿形式・紙・とじ方）

## 5. 試し刷りで確かめること

- ドロップアウトカラー：書くときに罫が見えるか。青のボールペン・鉛筆と見分けられるか（写真で）
- 目印とコード：スマホで斜めから撮っても読めるか。印刷のにじみで細いビットがつぶれないか
- 寸法：刷った紙を定規で測り、目印の間の長さがデータどおりか（プリンターの縮小で変わっていないか）
