# スキャン用の Palette ノート紙と取り込み

アナログのノート紙（Palette スキャンノート。B5・50 枚組みなど）に書いたものを、アプリの回のノートに取り込む。
写真を貼るのではなく、アプリの紙（刷った紙と同じ計算で描いた罫線）の上に、写真から取り出した**書いた線だけ**を同じ位置に重ねる。紙の汚れ・影・しわ・傾きは残らない。

## 1. 決めたこと

| 項目           | 決め                                                                                                                                                                    |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 紙の大きさ     | B5（182 × 257 mm）。原稿用紙だけ横                                                                                                                                      |
| 罫             | ショップで売っている全形式（`SCAN_FORMAT_IDS`。28 形式）。罫は **ドロップアウトカラー**（薄い水色 `#8fcbea`）で刷る                                                     |
| 罫を引くところ | 高さ 210 mm（セミ B5 のキャンパスノート・A 罫 30 行にそろえる）。上下は同じ幅（23.5 mm）。原稿用紙は上 20 mm・下 18 mm                                                  |
| 目印           | 四隅に黒（`#1a1a1a`）の 5 mm 角。紙の端から 6 mm。右下だけ中に白い四角（向きが分かる）                                                                                  |
| 形式のコード   | 下の端の真ん中。**全ページ同じ**（ページごとに変えない）。23 ビット（区切り 101・形式 6 ビット・版 4 ビット・検査 6 ビット・区切り 1011）。1 ビット 1.5 mm・高さ 3.5 mm |
| 授業・回の欄   | 紙には入れない。送り先は、撮った時刻と時間割から推し量り、スマホで確かめてから送る                                                                                      |
| 上の欄         | 日付の欄（`head: 'date'`）。上の線もドロップアウトカラー                                                                                                                |

## 2. 刷る紙とアプリの紙は同じ計算

- `shared/notebooks.js` の `scanDesign(format)` が、スキャン用の紙の設定（`size: 'b5'`・`scan: true`・罫の色）を返す
- `pageGeometry` は、`scan` なら四隅の目印と形式のコード（`shared/scan-code.js` の `scanMarks`）も描く
- 刷る紙（`scripts/scan-sheets.mjs`）も、取り込んだときのアプリの紙（回のノートのページ）も、この同じ設定・同じ計算で描く。目印とコードもアプリの紙に描き、刷った紙と同じ見た目にする

### 印刷データ

```
node scripts/scan-sheets.mjs [出力フォルダ]   # 既定は dist/scan
```

- `palette-scan-b5-all.pdf`：全形式を 1 ページずつ（試し刷り用）
- `palette-scan-b5-<形式>.pdf`：形式ごと（印刷所に渡し、50 枚に刷る）
- 家庭のプリンターでは「実際のサイズ（100%）」で、B5 の用紙に刷る。横罫は紙の端まで引くので、フチなしでないプリンターでは端が少し欠ける（目印とコードは端から 6 mm 以上内側なので欠けない）

## 3. 取り込みの流れ（これから作る）

1. スマホ（スマホ連携の「写真」に「ノートに取り込む」を足す）で撮るか、スキャナーの PDF・画像をパソコンに入れる
2. 四隅の目印を見つけ、射影変換で紙をまっすぐ・原寸に直す（右下の目印で向きを決める）
3. 下の端のコードを読み、紙の形式を知る（版を確かめる）
4. 色で書いた線だけを取り出す：ドロップアウトカラー（明るい水色）・紙の白・影を消し、暗い色（黒・青・赤のインク・鉛筆）を残す。インクの色は残す
5. 送り先の授業と回を決める（撮った時刻と時間割。スマホで確かめる）
6. 回のノートに、`scanDesign(形式)` の紙のページを足し、取り出した線を同じ位置に貼る（貼りもの。上からペン・マーカー・文字隠しを重ねられる）

すべてパソコンの中で処理する（クラウドに送らない。SPEC §5.2）。

## 4. 進め方

1. 仕様・印刷データ・目印とコードの計算（この版）
2. 取り込みの処理：目印の読み取り・ゆがみ直し・コードの読み取り・色の分離（見本の写真で試験する）
3. アプリへの組み込み：スマホの「ノートに取り込む」・パソコンへのドラッグ・回のノートにページを足す
4. 実物での調整：刷った紙に書いて撮り、ドロップアウトカラーの濃さ（書きやすさと消しやすさ）・目印の大きさ・コードの幅を直す
5. 売る紙の印刷データ（印刷所の入稿形式・紙・とじ方）

## 5. 試し刷りで確かめること

- ドロップアウトカラー：書くときに罫が見えるか。青のボールペン・鉛筆と見分けられるか（写真で）
- 目印とコード：スマホで斜めから撮っても読めるか。印刷のにじみで細いビットがつぶれないか
- 寸法：刷った紙を定規で測り、目印の間の長さがデータどおりか（プリンターの縮小で変わっていないか）
