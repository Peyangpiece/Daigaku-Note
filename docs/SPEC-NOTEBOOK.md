# 持ち物の「ノート」・マイノート・ノートのショップ（v0.19.0・試し書きと原稿用紙・五線譜の組み方は v0.19.3）

持ち物（筆箱・ポーチ）に 3 つ目の「ノート」を足す。回のノート（SPEC §8.6）の紙を、ショップで買ったノートから選べるようにし、
買ったノートは罫線の色・行の間・ページ上部の線などを調節して「マイノート」として保存できる。

## 1. 決めたこと

| 項目                 | 決め                                                                                                                                                                                          |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ブランド名           | 表紙の下に **Palette** と印字する（パレットノートのノートのブランド）。実在の商品名・ロゴ・表紙の柄は使わない                                                                                 |
| 表紙の基本の形       | 全テンプレートで同じ形（§4）。字は「Palette」だけで、テンプレートごとに変えるのは色だけ。一色の表紙・左の背・下に細い線と斜体の字（§4）。特定の商品の表紙は写さない                           |
| 品ぞろえ             | 学習ノートの代表的な罫（§3.1）と、ニッチな罫（§3.2）                                                                                                                                          |
| 値段                 | ポイント。今の 4 種類（横罫 6・7 mm、方眼 6・7 mm）にあたるノートは、はじめから持っている（0 pt）                                                                                             |
| マイノート           | 持っているノートをもとに、線の色・太さ・行の間・ページ上部の線・左の余白の線・紙の色などを変えて名前を付けて保存する。最大 30 冊                                                              |
| 幅を変えられるノート | 幅が名前に書いてあるノート（横罫・ドット入り罫線・方眼・ドット方眼・コーネル式）は、その幅のノートなので幅を変えない（`gapFixed`。v0.19.4）。変えられるのは英習罫・五線譜・原稿用紙・漢字練習 |
| 前の版との互換       | 今あるノート（紙 `v: 2`、`v` なし）は、ページを足しても前の見た目のまま。新しく作るノートは `v: 3`（§5）                                                                                      |

## 2. 画面

- **持ち物 → ノート**（`#/fudebako?tab=notes`）
  - 持っているノート：表紙と、ページの左上を拡大した見本（罫線がはっきり見える大きさ。`cropOf`）の札。押すと、そのノートをもとにした調節の画面
  - マイノート：保存したもの。押すと調節の画面（上書きか別名で保存）。「消す」
  - 「回のノートを作るときに最初に選ぶ紙」（既定）を 1 つ選べる
- **調節の画面**（`#/fudebako?tab=notes&edit=<マイノートの id>` か `&base=<ノートの id>`）
  - 左：ページの見本（A4 縦。実際に作る PDF と同じ計算で描く SVG）
  - 右：名前・罫線の色・線の太さ・行の間（方眼の幅）・ページ上部の線（なし・1 本・2 本・日付欄つき）と色・左の余白の線と色・罫の上の点（横罫）・太線の間隔（方眼）・紙の色
  - 「マイノートに保存」「別名で保存」「試し書き」
- **ショップ**：種類に「ノート」。札は表紙の絵、詳細ページはページ全体の見本・左上の拡大・罫の説明と「試し書き（実際の大きさ）」。持っていれば「マイノートで調節する」
- **試し書き**（`views/notebook-try.js`）：ページを実際の大きさ（CSS の mm。1.5 倍・2 倍にもできる）で開き、黒・青・赤・シャープで書ける。原稿用紙は A4 横で開く。書いたものは保存しない（アプリを開いている間だけ紙ごとに覚える）
- **回のノートの紙を選ぶメニュー**（授業画面の「＋ ノート」・PDF の編集画面の「ノート」「横に並べる」「紙を変える…」）：マイノート → 持っているノートの順に出す

## 3. 品ぞろえ

### 3.1 学習ノートの代表的な罫

A4 縦のページは、罫を引くところの高さを 245 mm にし、上下に 26 mm ずつ空ける（コクヨのキャンパスノート A4・A 罫 7 mm が 35 行＝245 mm。A 罫 35 行・B 罫 40 行・C 罫 49 行。上下の空け方は確かめられず、同じ幅にした。v0.19.4）。方眼は太線の間隔の倍数のますにそろえ、外のわくを太線で閉じる。漢字練習は上の線の下からますを並べ、外のわくを太くする。

罫の名前と幅は、販売店の商品ページで確かめた（コクヨの公式サイトはこの環境から開けなかった）。A 7 mm・B 6 mm・U 8 mm・UL 10 mm・ドット入り罫線・方眼 5 mm（10 mm 実線）・4 mm（8 mm 実線）・12 mm・英習罫は商品ページで確かめた。C 5 mm は商品ページでは確かめられず、一般に知られている幅にした。

| ---------------------- | ---------------------------------------------- | ---------------------------------------- |
| 横罫 A                 | 普通横罫                                       | 7 mm                                     |
| 横罫 B                 | 中横罫                                         | 6 mm                                     |
| 横罫 C                 | 細横罫                                         | 5 mm                                     |
| 横罫 U                 | 幅広横罫                                       | 8 mm                                     |

## 4. 表紙のデザイン（SVG。全テンプレート共通の形）

- 一色の表紙（色はテンプレートごと）。字は「Palette」だけで、ほかの字・札・柄は入れない
- 左に背（表紙の色を少し暗くした色）
- 下に細い線と、斜体の「Palette」。字と線は白。淡い表紙（明るさが 0.55 を超える色）では、表紙の色を濃くした色にする

## 5. データ

- `src/shared/notebooks.js`（新規。副作用なし）
  - `FORMATS`：罫の形式（種類・幅・太線・点・余白など）
  - `NOTEBOOKS`：ショップのノート（`type: 'notebook'`、`format`、`cover`（表紙の色）、`points`）
  - `cleanDesign(raw)`：紙の設定 `{v: 3, format, gap, line, weight, head, headColor, margin, marginColor, dots, bold, paper}` を整える
  - `pageGeometry(design)`：ページに描く線・点・塗る形（魚尾）を mm で返す。ページの大きさ（`pageSize`。原稿用紙は A4 横）も返す。PDF（メイン）と見本（SVG）が同じ計算を使う
  - `cropOf(design)`：一覧の札で拡大して見せるところ
  - `coverArt(item)`：表紙の SVG
- `src/shared/stationery.js`：品ぞろえ・種類（`notebook`）・はじめの品にノートを足す。持ち物の状態に `myNotes`（マイノート）と `noteDefault`（既定の紙）
- `src/main/note-pdf.js`：`v: 3` を `pageGeometry` で描く。ページの大きさは `pageSizePt`（原稿用紙は A4 横）。`v: 2`・`v` なしは今のまま
- IPC：`stationery.myNoteSave`・`stationery.myNoteRemove`・`stationery.noteDefault`

## 6. 進め方

1. `notebooks.js`（形式・品・設定・ページの計算・表紙）とテスト
2. PDF の `v: 3` とテスト（前の版のノートが変わらないことも）
3. 持ち物の状態（ノート・マイノート・既定）・IPC とテスト
4. 紙を選ぶメニューを、持っているノートとマイノートから出す
5. 持ち物の「ノート」・調節の画面・ショップの札と詳細
6. SPEC・CHANGELOG・版（0.19.0）。アプリで撮って確かめ、CI・公開の確認
