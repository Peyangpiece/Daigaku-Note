# スマホ連携（SPEC の別紙）

パソコンのパレットノートとスマホをつなぎ、スマホで「今日の復習」「資料と書き込みを見る・書く（コメント・マーカー・文字隠し・赤シート）」「写真で取り込む」をできるようにする。iPad では、パソコンとまったく同じ画面で同じ操作もできる（§8）。SPEC §5.2（クラウドを持たない）の方針はそのままにし、**データはパソコンの中だけに置く**。

## 1. 段階

| 段階                                    | スマホ側                                                     | つなぎ方                                                                     | できること                                                                                                            | できないこと                                       |
| --------------------------------------- | ------------------------------------------------------------ | ---------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| **1. Web 版**（いま作る）               | パソコンが配る Web ページ（QR を読んで開いたブラウザで使う） | 同じ Wi-Fi で、パソコンに直接（`http://<パソコンの LAN の IP>:<ポート>/m/`） | 今日の復習・資料と書き込みを見る・コメント／マーカー／文字隠しを書く・赤シート・写真を回のフォルダへ送る              | パソコンとつながっていないときの利用・スマホの通知 |
| **2. アプリ**（Apple の登録が通ったら） | 段階 1 と同じ画面を包んだアプリ（iPhone・Android）           | 同じ Wi-Fi のときにまとめてそろえ、外ではスマホに入れた分を使う              | 段階 1 ＋ 外での復習・資料を見る・書く（次に同じ Wi-Fi に入ったときにそろえる）・復習の時間の通知（スマホの中で出す） | 新しい資料が届いた瞬間の通知（クラウドが要る）     |

段階 1 の Web ページは HTTPS でない（LAN の IP には公開の証明書が出ない）ため、ブラウザの決まりでオフラインの保存（Service Worker）・通知・WebCrypto が使えない。外での利用と通知は段階 2 のアプリで行う。

## 2. つなぐ（パソコン：設定 → スマホ）

| 項目           | 仕様                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 入れる・切る   | 「スマホとつなぐ」をオンにしている間だけ、パソコンが LAN でページを配る（既定はオフ）。オフにする・パレットノートを終了すると止まる                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| つなぐ         | 「スマホを追加」（またはアナログノートの窓の「スマホとつなぐ」）を押すと QR を出す（https の入口）。①スマホのカメラで読むとブラウザでページが開き、「ホーム画面に追加してください」と案内する（ここではつながない。QR は使わない）②ホーム画面に追加した「パレットノート」のアイコンから開くと、カメラで QR を読む画面になる（jsQR）③パソコンの QR をもう一度読むと、そのままつながる（パスワードは要らない）。パソコンでアナログノートの窓を開いていれば、つながったその場で読み取りが始まる。QR は 10 分で無効になり、1 回つなぐと使えなくなる。前からブラウザでつないでいるスマホは、そのまま使える（v0.20.3）       |
| 鍵             | QR の中に、そのスマホ専用の鍵（32 バイトの乱数）と端末の番号を入れる。鍵は URL の `#` より後ろ（サーバーに送られない部分）に入れる。スマホが初めてつながったとき、パソコンは新しい鍵を作って QR の鍵と入れ替える（QR を写真に撮られても、つないだあとは使えない）。鍵はスマホはブラウザの中（localStorage）に、パソコンは OS の仕組みで暗号化して（safeStorage）持つ                                                                                                                                                                                                                                                   |
| つないだスマホ | 一覧に名前（スマホの種類から付ける。変えられる）・つないだ日・最後に使った日を出す。「外す」で鍵を消し、そのスマホからは何もできなくなる                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| アドレス       | パソコンの LAN の IP とポート（http は既定 47390、https は 47391。使えなければ空いている番号）。IP が変わる（ルーターが割り当て直す）と、前のアドレス（ホーム画面のアイコン・ブックマーク）では開けなくなるので、もう一度 QR を読んでホーム画面に追加し直す（アイコンの QR を読む画面は、入口の違う QR に「パソコンの入口が変わっています」と出す）。ホーム画面に追加するのは、iPhone ではホーム画面から開くページが Safari と保存場所が別で、ブラウザで覚えた鍵を使えないため（アイコンの中でつなぐ）。Android は manifest（`/m/app/manifest.webmanifest`。192・512 px のアイコン）で「アプリをインストール」も出せる |
| 大学の Wi-Fi   | 大学の Wi-Fi は端末どうしが通信できない設定のことが多い。スマホから届かなければ「パソコンとスマホが同じ Wi-Fi にあるか確かめてください（大学の Wi-Fi ではつながらないことがあります）」と出す                                                                                                                                                                                                                                                                                                                                                                                                                          |

## 3. 通信の安全

- やりとりはすべて、そのスマホの鍵で暗号化する（XChaCha20-Poly1305。`@noble/ciphers`。HTTPS でないページでは WebCrypto が使えないため JS で行う）。鍵のない端末・壊れた中身は読めず、答えない
- 1 回ごとに使い捨ての番号（nonce）と時刻を入れ、5 分より古いもの・同じ番号の 2 回目は受け付けない（盗み見た通信をそのまま送り直されても通らない）
- スマホができることは決めた窓口だけ（§4）。設定・接続・パスワード・API キー・バックアップなどには触れない
- 配るのは画面のファイル（HTML・JS・CSS・pdf.js）だけで、資料・注釈・問題は暗号化した窓口からだけ返す
- 鍵を知っている人だけが使えるので、QR を人に見せない（設定の画面にも書く）
- 窓口は LAN の誰でも送れるので、本文は端末を確かめてから読む：`Content-Length` を先に見て 48MB を超えれば読まずに断る（413）、先頭 26 バイトの端末の番号で鍵を引き、知らない端末は残りを読まずに断る（403）、QR を読んだだけの端末はあいさつの大きさ（4KB）まで。同時に受ける要求は 4 件まで（それより多ければ 503）、つなげる数は 32 まで、1 回の要求は 120 秒まで（v0.12.3）
- https（v0.20.2）：スマホのブラウザでカメラの映像を使う（アナログノートをその場で読む）ため、http（47390）に加えて https（47391）でも同じものを配る。スマホを追加する QR は https の入口にする。証明書はこのパソコンで作る自己署名（`main/mobile/tls-cert.js`。SAN に LAN の番号。秘密の鍵は `secrets.js`）なので、スマホは初めて開くときに警告を出す（進んでよいのは、このパソコンの QR から開いたときだけ）。通信の中身は、これとは別に上の端末ごとの鍵で暗号化している
- **段階 1 の限界**：ページ（画面のコード）は平文の HTTP で配り、鍵はスマホのブラウザの localStorage にそのまま置く。同じ Wi-Fi にいる人がパソコンのふりをして（IP を乗っ取って）書き換えたページを配ると、開いた瞬間に鍵を読まれうる。家の Wi-Fi で使う前提とし、カフェなど知らない人のいる Wi-Fi では使わない。段階 2（アプリに画面のコードを入れる）でなくなる
- **iPad のアプリ（v0.25.5）**：パソコンの画面はアプリに入っておらず、パソコンが http で配るページをアプリの中で開く。そのページは iPad の機能（Capacitor。ファイル・設定の保存）に届くので、上の限界はアプリにもそのまま当てはまる（同じ Wi-Fi でパソコンになりすました先のページも、iPad の中のデータに届く）。開く先は、家庭や大学の内向きの番号（10.x・172.16〜31.x・192.168.x）だけに限る（`ipad/src/qr.js` の `lanHost`・`ipad/capacitor.config.json` の `allowNavigation`）。外を指す QR は開かない
- **バックアップの読み込み（v0.25.5）**：パソコンにつないだ iPad（§8）からは受けない（`PAD_REMOTE_DENY`）。データベースを丸ごと入れ替える操作で、中の場所（資料・フォルダ・コマンド）を細工したデータベースを入れると、パソコンのファイルに届くため
- 暫定の見張り（v0.12.7）：つないだスマホが、前と違う所（IP）・違うブラウザ（User-Agent）からつながったら、パソコンに通知を出す（同じ所への変化は 1 日 1 回まで）。「心当たりがなければ、設定 → スマホとつなぐ で外してください」。設定の一覧には、最後につながった所を出す。ルーターが IP を割り当て直したときにも出ることがある

## 4. スマホでできること（窓口）

| 窓口           | 中身                                                                                                                                                                                                                                                                                                             |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ホーム         | 今日の復習の問題数・今日の授業（時間割と学期から。いまの時限の授業を先に）・最近の資料（新しい順に 20 件）・授業の一覧                                                                                                                                                                                           |
| 授業           | 授業ごとの回と資料（PDF・画像）                                                                                                                                                                                                                                                                                  |
| 資料を開く     | PDF の中身・注釈・前の版のしおり（パソコンの `pdf.open` と同じ）。注釈の一覧だけの取り直し（`annotation.list`）。貼ったシールの画像（`sticker.data`）。PDF 以外の資料は名前だけ（開けない）                                                                                                                      |
| 書く           | 注釈の保存・削除（コメント・マーカー・文字隠し。パソコンの `annotation.save`・`annotation.remove` と同じ検査）                                                                                                                                                                                                   |
| 復習           | 今日の復習の問題・答える（パソコンの `quiz.review`・`quiz.answer`）                                                                                                                                                                                                                                              |
| 写真を送る     | 撮った写真（JPEG・HEIC・PNG・WebP。中身の頭で確かめる。1 枚 30MB まで。1 回に 1 枚ずつ送る）を授業の回のフォルダへ（`material.uploadData` と同じ）                                                                                                                                                               |
| アナログノート | パソコンで「アナログノート…」の窓が開いているか（`scan.waiting`。送り先の授業・回）。撮る画面からは `watching` を付けて見る（パソコンに「スマホとつながっています」と出す）。撮った 1 枚（JPEG・PNG・WebP。スマホで JPEG にしてから送る）をその窓へ送り、読めたかを受け取る（`scan.send`。docs/SPEC-SCAN.md §3） |

## 5. スマホの画面

| 画面           | 仕様                                                                                                                                                                                                                                                                                                                                                                                                            |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ホーム         | 上から「今日の復習 ◯問（押すと復習）」「今日の授業（押すとその授業）」「最近の資料」。下に「授業の一覧」。右上に「アナログノート」「写真」。パソコンで「アナログノート…」の窓が開いていれば、いちばん上に「アナログノートを撮る」                                                                                                                                                                               |
| 授業           | 回ごとの資料。押すと開く。「この回に写真を送る」                                                                                                                                                                                                                                                                                                                                                                |
| 資料（PDF）    | ページを縦に並べて見る（指でスクロール・2 本指で拡大）。パソコンの書き込み（文字入れ・ペンの線・マーカー・文字隠し・コメント・貼った図やシール・付箋）をそのまま出す。下の道具：見る／コメント／マーカー／隠す／消す。上に「赤シート」と「付箋」（付箋の一覧。押すとその場所へ。付箋はパソコンで貼る）。パソコンで書いた分は、スマホの画面に戻ったときと、開いている間は 30 秒ごとに取り直す                    |
| 書く           | コメント：押した所にアイコンを置き、本文を打つ。マーカー・文字隠し：なぞった所に引く（指 1 本。文字の行と字の切れ目に合わせるのはパソコンと同じ。文字隠しは押すだけなら 1 語）。マーカーは 4 色と太さ。ページを動かすのは「見る」の道具で。消す：押したコメント・マーカー・文字隠しを消す（パソコンで書いたものも。消したあと「元に戻す」を出す）。文字入れ・ペンの線・貼りものは見るだけ（直すのはパソコンで） |
| 赤シート       | 画面の上に赤い下敷きを出し、指でずらす。下に入った文字隠しは黒く、赤い文字入れ・赤いペンの線は見えなくなる（パソコンと同じ見え方）                                                                                                                                                                                                                                                                              |
| 復習           | 1 問ずつ。答えを選ぶ（選択・正誤・穴埋め）・数を打つ（数値）・答えを見て「できた／まだ」（記述カード）。結果はすぐパソコンに保存し、パソコンの「今日の復習」と同じ記録になる                                                                                                                                                                                                                                    |
| 写真           | カメラを開いて撮る（または写真を選ぶ）。送る先は「いまの時限の授業と、今日の回」を初めから選んでおく（時間外なら今日このあとの授業、なければ最後に開いた授業）。送った写真はパソコンの回のフォルダに入り、資料の一覧に出る                                                                                                                                                                                      |
| アナログノート | パソコンで開いた「アナログノート…」の窓へ撮って送る。パソコンで押すと、この画面に自分で切り替わる（ほかの画面から 3 秒ごとに見る。資料・復習の途中は知らせだけ）。送り先（授業・回）・大きな「撮る」（カメラが開く。写真を選ぶ方法はない）・送った写真ごとの結果（読めた形式・読めない理由）。窓が開いていなければ開き方を出し、2 秒ごとに見直す                                                                |
| つながらない   | 「パソコンのパレットノートが開いていて、『スマホとつなぐ』がオンで、同じ Wi-Fi にあるか確かめてください」と出し、もう一度試すボタン                                                                                                                                                                                                                                                                             |

## 6. パソコンとそろえる

- 段階 1 では、スマホの操作はその場でパソコンに書き込む（スマホは中身を持たない）。食い違いは起きない
- スマホで書き込んだ PDF をパソコンで開いていれば、その画面にすぐ出す。パソコンのファイルの上書き（注釈を描き込んだ PDF）は、次にパソコンでその PDF を開いたときに行う（文字入れの画像はパソコンの画面が描くため）
- 段階 2 では、注釈 1 つずつに「最後に変えた時刻」を持ち、同じ Wi-Fi に入ったときにまとめてそろえる（新しいほうを残す。消したものも記録して両方から消す）

## 7. 段階 2 の準備（Apple・Google の登録）

- Apple Developer Program（年 99 ドル）：登録が有効になるまで目安 24〜48 時間だが、身分証の確認で数週間かかることがある。先に申し込んでおく
- Google Play のデベロッパー登録（一度だけ 25 ドル）
- アプリは段階 1 の画面を Capacitor で包む。LAN の通信は、アプリでは iPhone の「ローカルネットワーク」の許可を求める

## 8. パソコンと同じ画面（iPad。v0.21.0）

iPad など大きな画面の端末で、**パソコンのパレットノートとまったく同じ画面を、同じ操作で**使う。パソコンの画面（`src/renderer`）を、そのまま iPad のブラウザで動かす。データはこれまでどおりパソコンの中だけに置く（iPad は画面だけ）。

| 項目         | 仕様                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 使えるとき   | パソコンのパレットノートが開いていて、「スマホとつなぐ」がオンで、同じ Wi-Fi にあるあいだ（段階 1 と同じ）                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| オンにする   | スマホと同じ手順（§2）でつないだあと、パソコンの 設定 → スマホ の一覧で、その端末の「パソコンと同じ画面を使う」をオンにする（既定はオフ。オンにするときに確かめる）。オンの端末は、iPad（と大きな画面）ではスマホのページ（`/m/`）を開くと自分でこの画面（`/m/p/`）へ移る。スマホのページのいちばん下にも「パソコンと同じ画面で開く」。この画面の 設定 → スマホ に「スマホの画面に切り替える」。ホーム画面に追加したアプリの範囲（manifest の scope）は `/`（`/m/` と `/p/` の両方。`/m/` だけだと `/p/` がアプリの外とみなされ、Safari のバーが出る。v0.21.1） |
| 配るもの     | `/m/p/src/renderer/`（パソコンの画面）・`/m/p/src/shared/`・`/m/p/node_modules/pdfjs-dist/`・`/m/p/node_modules/three/`・`/m/p/pad/`（`src/pad`）。`/m/` の下に置くのは、ホーム画面のアプリの範囲が `/m/` のままのアイコンでもアプリの中として開くため（v0.21.2。`/p/` は `/m/p/` へ移す）。画面のファイルには ETag を付け、変わっていなければ 304（送り直さない）。`index.html` は配るときに直す：画面の幅に合わせる・`pad.css` を足す・暗号の部品を import の対応表に足して CSP のハッシュも直す・`app.js` の前に `pad/boot.js` を読む                        |
| 窓口         | パソコンの画面の窓口（preload の INVOKE）を、スマホと同じ暗号化した窓口（`/m/api`）の `pad.call` で送り、パソコンの窓口（`ipc/*.js` の handle）をそのまま呼ぶ（`main/mobile/pad.js`）。答えはパソコンの画面と同じ形（失敗は `{error}`）。iPad の画面は、パソコンの画面（WebFrameMain）に見立てて渡す（書いた画面以外に知らせる・アナログノートの写真を渡すのも同じ）                                                                                                                                                                                            |
| 知らせ       | パソコンの画面への知らせ（`state.changed`・`sync.progress`・`quiz.finished`・`annotations.changed`・`note.pages` など）を、iPad の画面ごとに貯め、`pad.poll` で長く（25 秒まで）待って渡す（`frames.js` の `tapPad`）。並べた左右の画面（iframe）も、上の画面の 1 つの待ちで受ける。取りこぼした（300 件を超えた・パソコンのアプリを開き直した）ときは全部を読み直す。知らせの待ちは、窓口の同時の数（4 件）に数えない（8 つまで）                                                                                                                              |
| そろえる     | 一方で変えたら（フォルダ・回・資料・設定など）、もう一方の画面に `state.changed` を知らせる（読むだけのもの・書き込みのたびのもの・終わってから自分で知らせるものは除く。`PAD_QUIET`） 。PDF のファイルへの上書き（文字入れを画像にして送り、PDF を作り直す）は iPad では手を止めるたびにはせず、パソコンで次に開いたときに行う（`pdf.markStale`。スマホと同じ `pdf.stale`。v0.21.2）。持ち物の 3D モデルは、暗号化した窓口を通さずブラウザで直接読む（アプリの部品で資料ではない）                                                                             |
| ファイル     | パソコンの選ぶ・保存する窓や、パソコンのアプリで開くものは、iPad で行う（`PAD_LOCAL`）：資料を入れる（iPad でファイルを選ぶ）・資料を開く（Word・画像などを iPad で開く）・注釈付きで書き出す・バックアップの書き出し（iPad に保存する）・学年暦を読む・バックアップの読み込み（iPad で選ぶ）・外のページを開く。ファイル 1 つは 90MB まで（暗号化して運ぶため。それより大きなものはパソコンで）                                                                                                                                                                |
| 指           | 指の長押しは右クリック（パソコンの画面の右クリックのメニュー）。Apple Pencil はペン（筆圧も）。手のひら：文字を打つ欄の外では文字を選ばない（PDF の文字はマウス・トラックパッドのときだけ）。ペンを使っている間・使った直後（1.5 秒）と、ペンで書いた画面では、長押しのメニューを出さない（v0.21.1）。ペンで書いている間と手を止めて 2 秒の間は、`state.changed` を待たせてまとめる（受けた画面は状態を全部読み直すので、書いている線が遅れる）                                                                                                                 |
| できないこと | パソコンのフォルダ・窓を開く（Finder で開く・データとログの場所・バックアップの場所）、パソコンのフォルダを選ぶ（保存先のフォルダ・パソコンのフォルダを登録する）、スマホ・iPad をつなぐ設定（入れる・切る・追加・パソコンと同じ画面のオン）。LMS に初めてログインするときの窓（大学のログインの画面）はパソコンの画面に出る（保存したパスワードでの自動のログインは iPad からも使える）                                                                                                                                                                        |
| つながらない | 上に「パソコンとつながっていません」の帯を出し、つながるまで試し続ける。つながったら全部を読み直す。パソコンで外された・オフにされたときは、その案内を出す                                                                                                                                                                                                                                                                                                                                                                                                      |

安全：オンにした端末は、設定（LMS の接続・AI のキー・バックアップなど）もこの端末から変えられる（パスワード・キーの中身は、パソコンの画面と同じく返さない）。§3 の段階 1 の限界（画面のコードを平文で配る・鍵をブラウザに置く）はこの画面にも当てはまり、鍵を盗まれたときにできることが広くなるので、オンにするのは自分の iPad だけ・家の Wi-Fi で使う。本文の大きさの上限は、オンの端末だけ 128MB（ほかは 48MB のまま）

### 8.1 iPad のアプリ（App Store。`ipad/`。v0.22.2）

- Capacitor（8.5）で包んだアプリ。バンドル ID `jp.daigakunote.ipad`・チーム `9G78U9XD92`・iPad 専用。配布は TestFlight（`.github/workflows/ipad.yml`：既定のブランチで版が上がったら、App Store Connect API キーで署名して送る。ビルド番号は実行の番号）
- 最初の画面（`ipad/src`。アプリの中に入れる）：パソコンの QR をカメラで読み、QR の `hp`（http の入口の番号）でパソコンの `/m/` をアプリの中で開く。パソコンの入口を覚え、次からはすぐ開く（届かなければ知らせる）。アプリはこのパソコンが作った証明書の https を開けないので http を使う（窓口の中身は §3 の端末ごとの鍵で暗号化している。LAN の http は `NSAllowsLocalNetworking`）
- アプリの中で開いたページは、ホーム画面に追加したアイコンと同じ扱い（User-Agent の `PaletteNoteApp`。QR の # でつなぐ）。大きな画面なので、オンの端末は §8 のとおり `/m/p/` へ移る
- パソコンなしで使う部分（Google ドライブ）は v0.23〜0.25 で入れた（docs/SYNC.md §7〜§12）
