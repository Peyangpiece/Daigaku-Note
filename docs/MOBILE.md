# スマホ連携（SPEC の別紙）

パソコンの大学ノートとスマホをつなぎ、スマホで「今日の復習」「資料と書き込みを見る・書く（コメント・マーカー・文字隠し・赤シート）」「写真で取り込む」をできるようにする。SPEC §5.2（クラウドを持たない）の方針はそのままにし、**データはパソコンの中だけに置く**。

## 1. 段階

| 段階                                    | スマホ側                                                     | つなぎ方                                                                     | できること                                                                                                            | できないこと                                       |
| --------------------------------------- | ------------------------------------------------------------ | ---------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| **1. Web 版**（いま作る）               | パソコンが配る Web ページ（QR を読んで開いたブラウザで使う） | 同じ Wi-Fi で、パソコンに直接（`http://<パソコンの LAN の IP>:<ポート>/m/`） | 今日の復習・資料と書き込みを見る・コメント／マーカー／文字隠しを書く・赤シート・写真を回のフォルダへ送る              | パソコンとつながっていないときの利用・スマホの通知 |
| **2. アプリ**（Apple の登録が通ったら） | 段階 1 と同じ画面を包んだアプリ（iPhone・Android）           | 同じ Wi-Fi のときにまとめてそろえ、外ではスマホに入れた分を使う              | 段階 1 ＋ 外での復習・資料を見る・書く（次に同じ Wi-Fi に入ったときにそろえる）・復習の時間の通知（スマホの中で出す） | 新しい資料が届いた瞬間の通知（クラウドが要る）     |

段階 1 の Web ページは HTTPS でない（LAN の IP には公開の証明書が出ない）ため、ブラウザの決まりでオフラインの保存（Service Worker）・通知・WebCrypto が使えない。外での利用と通知は段階 2 のアプリで行う。

## 2. つなぐ（パソコン：設定 → スマホ）

| 項目           | 仕様                                                                                                                                                                                                                                                                                                                                                                 |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 入れる・切る   | 「スマホとつなぐ」をオンにしている間だけ、パソコンが LAN でページを配る（既定はオフ）。オフにする・大学ノートを終了すると止まる                                                                                                                                                                                                                                      |
| つなぐ         | 「スマホを追加」を押すと QR を出す。スマホのカメラで読むと、スマホのブラウザでページが開き、そのままつながる（パスワードは要らない）。QR は 10 分で無効になり、1 回つなぐと使えなくなる                                                                                                                                                                              |
| 鍵             | QR の中に、そのスマホ専用の鍵（32 バイトの乱数）と端末の番号を入れる。鍵は URL の `#` より後ろ（サーバーに送られない部分）に入れる。スマホが初めてつながったとき、パソコンは新しい鍵を作って QR の鍵と入れ替える（QR を写真に撮られても、つないだあとは使えない）。鍵はスマホはブラウザの中（localStorage）に、パソコンは OS の仕組みで暗号化して（safeStorage）持つ |
| つないだスマホ | 一覧に名前（スマホの種類から付ける。変えられる）・つないだ日・最後に使った日を出す。「外す」で鍵を消し、そのスマホからは何もできなくなる                                                                                                                                                                                                                             |
| アドレス       | パソコンの LAN の IP とポート（既定 47390。使えなければ空いている番号）。IP が変わる（ルーターが割り当て直す）と、前のアドレス（ブラウザのブックマークなど）では開けなくなるので、もう一度 QR を読む（スマホ側は「つなぎ直してください」と出す）。iPhone の「ホーム画面に追加」は使わない（ホーム画面から開くページは Safari と保存場所が別で、QR で覚えた鍵がない） |
| 大学の Wi-Fi   | 大学の Wi-Fi は端末どうしが通信できない設定のことが多い。スマホから届かなければ「パソコンとスマホが同じ Wi-Fi にあるか確かめてください（大学の Wi-Fi ではつながらないことがあります）」と出す                                                                                                                                                                        |

## 3. 通信の安全

- やりとりはすべて、そのスマホの鍵で暗号化する（XChaCha20-Poly1305。`@noble/ciphers`。HTTPS でないページでは WebCrypto が使えないため JS で行う）。鍵のない端末・壊れた中身は読めず、答えない
- 1 回ごとに使い捨ての番号（nonce）と時刻を入れ、5 分より古いもの・同じ番号の 2 回目は受け付けない（盗み見た通信をそのまま送り直されても通らない）
- スマホができることは決めた窓口だけ（§4）。設定・接続・パスワード・API キー・バックアップなどには触れない
- 配るのは画面のファイル（HTML・JS・CSS・pdf.js）だけで、資料・注釈・問題は暗号化した窓口からだけ返す
- 鍵を知っている人だけが使えるので、QR を人に見せない（設定の画面にも書く）
- 窓口は LAN の誰でも送れるので、本文は端末を確かめてから読む：`Content-Length` を先に見て 48MB を超えれば読まずに断る（413）、先頭 26 バイトの端末の番号で鍵を引き、知らない端末は残りを読まずに断る（403）、QR を読んだだけの端末はあいさつの大きさ（4KB）まで。同時に受ける要求は 4 件まで（それより多ければ 503）、つなげる数は 32 まで、1 回の要求は 120 秒まで（v0.12.3）
- **段階 1 の限界**：ページ（画面のコード）は平文の HTTP で配り、鍵はスマホのブラウザの localStorage にそのまま置く。同じ Wi-Fi にいる人がパソコンのふりをして（IP を乗っ取って）書き換えたページを配ると、開いた瞬間に鍵を読まれうる。家の Wi-Fi で使う前提とし、カフェなど知らない人のいる Wi-Fi では使わない。段階 2（アプリに画面のコードを入れる）でなくなる
- 暫定の見張り（v0.12.7）：つないだスマホが、前と違う所（IP）・違うブラウザ（User-Agent）からつながったら、パソコンに通知を出す（同じ所への変化は 1 日 1 回まで）。「心当たりがなければ、設定 → スマホとつなぐ で外してください」。設定の一覧には、最後につながった所を出す。ルーターが IP を割り当て直したときにも出ることがある

## 4. スマホでできること（窓口）

| 窓口       | 中身                                                                                                                                                                                        |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ホーム     | 今日の復習の問題数・今日の授業（時間割と学期から。いまの時限の授業を先に）・最近の資料（新しい順に 20 件）・授業の一覧                                                                      |
| 授業       | 授業ごとの回と資料（PDF・画像）                                                                                                                                                             |
| 資料を開く | PDF の中身・注釈・前の版のしおり（パソコンの `pdf.open` と同じ）。注釈の一覧だけの取り直し（`annotation.list`）。貼ったシールの画像（`sticker.data`）。PDF 以外の資料は名前だけ（開けない） |
| 書く       | 注釈の保存・削除（コメント・マーカー・文字隠し。パソコンの `annotation.save`・`annotation.remove` と同じ検査）                                                                              |
| 復習       | 今日の復習の問題・答える（パソコンの `quiz.review`・`quiz.answer`）                                                                                                                         |
| 写真を送る | 撮った写真（JPEG・HEIC・PNG・WebP。中身の頭で確かめる。1 枚 30MB まで。1 回に 1 枚ずつ送る）を授業の回のフォルダへ（`material.uploadData` と同じ）                                          |

## 5. スマホの画面

| 画面         | 仕様                                                                                                                                                                                                                                                                                                                                                                                                            |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ホーム       | 上から「今日の復習 ◯問（押すと復習）」「今日の授業（押すとその授業）」「最近の資料」。下に「授業の一覧」。右上に「写真」                                                                                                                                                                                                                                                                                        |
| 授業         | 回ごとの資料。押すと開く。「この回に写真を送る」                                                                                                                                                                                                                                                                                                                                                                |
| 資料（PDF）  | ページを縦に並べて見る（指でスクロール・2 本指で拡大）。パソコンの書き込み（文字入れ・ペンの線・マーカー・文字隠し・コメント・貼った図やシール・付箋）をそのまま出す。下の道具：見る／コメント／マーカー／隠す／消す。上に「赤シート」と「付箋」（付箋の一覧。押すとその場所へ。付箋はパソコンで貼る）。パソコンで書いた分は、スマホの画面に戻ったときと、開いている間は 30 秒ごとに取り直す                    |
| 書く         | コメント：押した所にアイコンを置き、本文を打つ。マーカー・文字隠し：なぞった所に引く（指 1 本。文字の行と字の切れ目に合わせるのはパソコンと同じ。文字隠しは押すだけなら 1 語）。マーカーは 4 色と太さ。ページを動かすのは「見る」の道具で。消す：押したコメント・マーカー・文字隠しを消す（パソコンで書いたものも。消したあと「元に戻す」を出す）。文字入れ・ペンの線・貼りものは見るだけ（直すのはパソコンで） |
| 赤シート     | 画面の上に赤い下敷きを出し、指でずらす。下に入った文字隠しは黒く、赤い文字入れ・赤いペンの線は見えなくなる（パソコンと同じ見え方）                                                                                                                                                                                                                                                                              |
| 復習         | 1 問ずつ。答えを選ぶ（選択・正誤・穴埋め）・数を打つ（数値）・答えを見て「できた／まだ」（記述カード）。結果はすぐパソコンに保存し、パソコンの「今日の復習」と同じ記録になる                                                                                                                                                                                                                                    |
| 写真         | カメラを開いて撮る（または写真を選ぶ）。送る先は「いまの時限の授業と、今日の回」を初めから選んでおく（時間外なら今日このあとの授業、なければ最後に開いた授業）。送った写真はパソコンの回のフォルダに入り、資料の一覧に出る                                                                                                                                                                                      |
| つながらない | 「パソコンの大学ノートが開いていて、『スマホとつなぐ』がオンで、同じ Wi-Fi にあるか確かめてください」と出し、もう一度試すボタン                                                                                                                                                                                                                                                                                 |

## 6. パソコンとそろえる

- 段階 1 では、スマホの操作はその場でパソコンに書き込む（スマホは中身を持たない）。食い違いは起きない
- スマホで書き込んだ PDF をパソコンで開いていれば、その画面にすぐ出す。パソコンのファイルの上書き（注釈を描き込んだ PDF）は、次にパソコンでその PDF を開いたときに行う（文字入れの画像はパソコンの画面が描くため）
- 段階 2 では、注釈 1 つずつに「最後に変えた時刻」を持ち、同じ Wi-Fi に入ったときにまとめてそろえる（新しいほうを残す。消したものも記録して両方から消す）

## 7. 段階 2 の準備（Apple・Google の登録）

- Apple Developer Program（年 99 ドル）：登録が有効になるまで目安 24〜48 時間だが、身分証の確認で数週間かかることがある。先に申し込んでおく
- Google Play のデベロッパー登録（一度だけ 25 ドル）
- アプリは段階 1 の画面を Capacitor で包む。LAN の通信は、アプリでは iPhone の「ローカルネットワーク」の許可を求める
