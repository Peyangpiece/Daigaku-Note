# 大学ノート 着せ替え 仕様書（別紙）

| 項目 | 内容 |
|---|---|
| 文書の版 | 0.1 |
| 作成日 | 2026-10-21 |
| 位置づけ | 本体の仕様書（SPEC.md）§8.0「デザイン方針」の上に、利用者が見た目を変えられる仕組みを足す。色の出どころは §8.0.2 の CSS 変数のまま。着せ替えはその値を差し替える |
| 状態 | 方針確定。第 1 弾から作る |

本書は「何を作るか」を決める。関数名やファイル分けは決めないが、画面の動き・決まり・データの形・作る順番は、作る人が迷わない粒度まで書く。

---

## 1. 目的（顧客体験価値）

| 価値 | ねらい |
|---|---|
| 機能 | 授業ごとに色・シールを変えて、目当ての授業を一目で見つける。「試験」「課題」などの意味のあるシールで、授業の状態を見てわかるようにする |
| 情緒 | 選んだその場で変わる楽しさ。自分で手をかけた文房具への愛着（使い続ける理由） |
| 自己表現 | 色だけでなく、自分の画像をシールとして貼り、ほかにない見た目にする |
| 手間を減らす | テンプレートから 1 手で選べる。何も設定しなくても整った見た目。はじめに自動で割り当てる |

**守ること**
- 着せ替えは本来の目的（資料をそろえて、書いて、覚える）の邪魔をしない。
- 文字の読みやすさ（§8.0.1「読みやすさは譲らない」。本文 15px 以上、コントラスト 4.5:1 以上）は、どんな着せ替えでも保つ。

---

## 2. 用語

| 用語 | 意味 |
|---|---|
| 部品 | 着せ替えの対象。ノート・フォルダ・マスキングテープ・ファイル・付箋・しおり |
| テンプレート | 部品の見た目一式に名前を付けたもの。**はじめからあるもの**（消せない）と**自作**がある |
| 対象 | テンプレートを当てる先。**全体**（すべての授業の既定）または**授業**（その授業だけ） |
| シール | 画像を部品に貼ったもの。位置・大きさ・傾き・重なり順を持つ |
| シール帳 | 取り込んだ画像（シールの素）をためておく場所 |
| パック | 複数のテンプレートとシールをまとめた束（§8 のショップへの道で使う） |

## 3. 画面

### 3.1 上の固定ボタン

- 画面の上に **［ホーム］［着せ替え］** を固定して置く。スクロールしても動かない。
- アイコンと文字の小さめのボタンにする。本来の画面を主役のままにするため、目立たせすぎない。今いる画面のボタンは押した状態で表示する。
- 置き場所は上余白（96px の帯）の右寄り。アプリ名・学期・日付と同じ帯に並べる。日付は左へ寄せる。
- **PDF 編集画面には出さない。** 上を編集のツールバーが使っており、「← 授業へ」で戻れるため。
- 設定への入口は、今までどおりホームの下に置く。

### 3.2 着せ替えページ（2 段構え）

**上：対象の切り替え** — 「対象：すべての授業 ▾」。授業を選ぶと、その授業だけの着せ替えになる。

**おすすめから選ぶ（最初に見える）**
- テンプレートの一覧を、ホームの縮小見本の形で並べる。
- 押すとすぐ当たる。今の対象で使っているものに ✓ を付ける。
- 授業を対象にしているときは、一覧のいちばん上に「全体と同じ」を出す。

**細かい編集（別のページ）**

着せ替えページの「細かい編集へ」ボタン、またはテンプレートの「直す」「もとにして作る」で、細かい編集のページ（`#/kisekae/edit`）へ移る。「← 着せ替えへ」で戻る（直した内容があれば、捨ててよいか確かめる）。保存すると着せ替えページへ戻る。

見本を直接さわって直す。左に見本とシール帳、右に「変える」欄を置く。

| 左：見本（場面を切り替える） | 右：変える |
|---|---|
| ホーム・授業ページ・PDF の 3 つの場面。今の設定で描いた縮小版で、変えるとすぐ反映される。下にシール帳 | 見本で押した部分（または上の部品の札で選んだ部分）の色・柄。シールを選んでいれば、そのシールの大きさ・傾き・重なり順 |

- 見本の部分（紙・フォルダ・テープ・ファイル・付箋・しおり）を押すと、右がその部分の設定になる。乗せると点線で囲み、選んでいる部分は実線で囲む。
- 右の色の見本にマウスを乗せると、押す前に見本へ映す（外すと戻す）。
- ファイルを押すと「ファイル」の場面になり、選んでいる種類の資料のイラストを大きく出す（下の小さなイラストで種類を切り替える）。イラストの中の種類の印（PDF の文字など）と拡張子のラベルは、ドラッグで動かし、Delete（または右の「消す」）で消せる。右の「出す」「元の位置に」で戻せる。テンプレートには `parts.fileArt`（種類ごとに、印とラベルの元の位置からのずれ dx・dy（±40）と、出すかどうか on）として保存する。
- 取り消し・やり直し（↶ ↷、⌘Z / Ctrl+Z、⇧⌘Z / Ctrl+Y）。50 回まで。

- 直した内容は、自作のテンプレートとして保存する。
  - はじめからあるテンプレートを直したときは、「複製して保存」にする。
  - 自作のテンプレートを直したときは、そのまま上書きする。ただし、保存の前に「**このテンプレートは 3 つの授業で使っています。すべて変わります**」と知らせ、［保存］［この授業用に複製］［やめる］から選んでもらう。
- 自作のテンプレートは、名前の変更・複製・削除ができる。
  - 削除すると、それを使っていた授業は「全体と同じ」に戻る。
  - 全体で使っているものを削除したときは、全体の既定に戻る。

### 3.3 フォルダの右クリック →「着せ替え…」（選択パネル）

フォルダのすぐ横に、小さなパネルを出す。着せ替えページへは移らない。

```
┌──────────────────────────┐
│ 管理会計Ⅱ の着せ替え          │
├──────────────────────────┤
│ ◉ 全体と同じ                 │
│ ─────────────            │
│ [見本] クリーム × 黄テープ      │
│ [見本] ミント × ストライプ  ✓   │
│ [見本] わたしの 1（自作）       │
│   …                       │
├──────────────────────────┤
│ ＋ 新しく作成                │
└──────────────────────────┘
```

| 操作 | 動き |
|---|---|
| 項目を押す | その場でフォルダに当たる。保存や決定のボタンはない。パネルは開いたままで、続けて試せる |
| マウスを乗せる | 本物のフォルダが仮にその見た目になる。外すと元に戻る。タッチ画面では押したときだけ |
| 切り替えたあと | 「元に戻す」付きのお知らせを出す。1 回で戻せる |
| 全体と同じ | その授業だけの設定をやめる |
| ＋ 新しく作成 | 着せ替えページを、この授業を対象にし、今の見た目をもとにした状態で開く。名前を付けて保存すると、テンプレートに加わり、この授業に当たる |
| 閉じる | パネルの外を押すか Esc。キーボードでは ↑↓ で選び、Enter で決める |

## 4. 決まり

### 4.1 どのテンプレートが当たるか
1. 授業にテンプレートを選んであれば、それを使う。
2. 選んでいなければ（「全体と同じ」）、全体のテンプレートを使う。

全体も授業も、同じテンプレートの一覧から選ぶ。

### 4.2 テンプレートはつながる
- 授業は、テンプレートの見た目を写して持つのではなく、「どのテンプレートを使うか」を覚える。そのため、自作のテンプレートを直すと、使っている授業がみな変わる。
- 1 つの授業だけ変えたいときは「この授業用に複製」で切り離す。

### 4.3 シールの重なり（全体と授業）
授業ごとに、次の 3 つから選ぶ。

| 選択 | 貼られるシール |
|---|---|
| 全体のシールだけ（既定） | 全体のテンプレートのシール |
| この授業のシールだけ | 授業のテンプレートのシール |
| 両方 | 全体のシールの上に、授業のシールを重ねる |

### 4.4 はじめての割り当て
- **今ある授業**：全体のテンプレートを、はじめからある「クラシック」にする。「クラシック」は、テープとバッジの色に**授業の色**（今の 8 色のうち授業ごとに決まっている色）を、テープの柄に**授業の柄**を使う。そのため、この機能を入れた版に更新しても見た目は変わらず、一覧にも同じものが並ばない。更新したあとに 1 回だけ、「着せ替えができるようになりました」と知らせる。
- **新しい授業**：はじめからあるテンプレートを順に割り当て、となり同士が同じ見た目にならないようにする。

### 4.5 ダークモード
- 選んだ色は、色合いを保ったまま明るさを下げた色にして使う。計算の決まりは、作るときに見本で確かめて決める。
- 文字の色（白・黒）は、背景の色からコントラストを計算して決める。4.5:1 以上になる方を選ぶ。

### 4.6 読みやすさ
- 色を自由に選べる部品はすべて、その上の文字の色を自動で決める（4.5 と同じ計算）。
- シールが授業名などの文字に重なったら、文字の下に薄い帯（紙の色、不透明度 80% ほど）を自動で敷く。
- 1 か所に貼れるシールは 5 枚まで。

## 5. 部品と変えられること

| 部品 | 色・柄 | シール | 対象 | 弾 |
|---|---|---|---|---|
| ノート | 種類 6 つ（下の表）、紙の色、線の色、線の間隔（狭い 24px／ふつう 32px／広い 40px）、余白の縦線の有無、線の濃さ（今の設定画面の「罫線」を移す） | ホームの余白（紙の上） | 全体だけ（紙はアプリ全体のため） | 1（シールは 2） |
| フォルダ | カードの色、タブの色 | 貼れる | 全体・授業 | 1 |
| マスキングテープ | 色、柄（無地・ストライプ・ドット・チェック） | 画像をテープの柄にできる（選んだ色の無地のテープの上に重ねる） | 全体・授業 | 1（画像の柄は 2） |
| 授業ページの見出し | － | 見出しのまわり | 全体・授業 | 2 |
| 付箋 | 回の付箋の色の並び、PDF に貼る付箋の色の候補 | 回の付箋に 1 枚（初めは角。動かせる） | 全体・授業 | 3 |
| ファイル | 種類ごとの色（PDF・スライド・文書・表…） | 種類ごとに 1 枚（初めは左上。動かせる） | 全体・授業 | 3 |
| しおり | リボンの色と形 | リボンに 1 枚（初めは先。動かせる） | 全体・授業 | 3 |
| PDF 編集画面の余白 | － | PDF のまわりの紙の上 | 全体・授業 | 2 |

色はすべて、見本の色に加えて色の選び器で好きな色を選べる。選んだ色は「最近使った色」に 8 つまで並べる。

**ノートの種類**

| 種類 | 見た目 |
|---|---|
| 横罫 | 今の背景。横の線 |
| 方眼 | 縦横の線 |
| ドット | 小さな塗りつぶしの点を格子状に並べる |
| 丸ドット | 中央がくり抜かれた小さな輪を格子状に並べる |
| 無地 | 線なし |
| コーネル | 横罫に、左の見出し欄の縦線と、下の要約欄の横線を足す（要約欄の線は画面の内容の終わりの近く。PDF 編集画面では出さない） |

**しおりの見た目（第 3 弾で新しく作る）**
- 編集画面：ページの右端から出るリボン。押すとそのページへ移る。
- 授業ページ：しおりのある資料の端から出るリボン。

## 6. シール

### 6.1 シール帳
- **取り込める画像**：PNG・JPEG・WebP（GIF は 1 枚目だけ）。
- **取り込みの処理**：長辺 512px 以内に縮め、PNG に描き直して保存する。描き直す理由は、画像の中の付加情報（位置情報など）を落とすことと、壊れた画像や細工された画像を持ち込まないこと。元の画像を消しても、シールは残る。
- **形**：背景が透明な画像は、絵の形どおりのシールになる。背景のある画像は、「そのまま」「角丸」「丸」「白いふち付き」から選ぶ。白いふち付きは、白いふちと薄い影を付けたシールらしい見た目。
- **整理**：自分でフォルダ分けとお気に入りを付けられる。
- **はじめから入っているシール**：20 枚ほど。
  - 飾り：星・ハート・花丸・矢印など
  - 意味のあるシール：「試験」「課題」「小テスト」「重要」「休講」

  締め切りに合わせて自動で貼る機能は、LMS から締め切りの情報が取れる場合に限り、第 2 弾以降で別に検討する。

### 6.2 貼り方
- シール帳から、見本（または本物の部品）の上へドラッグして貼る。
- 貼ったシールは、見本の上で次の操作ができる（選ぶと、点線の枠と取っ手が出る）。
  - 位置を動かす：そのままドラッグ。矢印キーでも（⇧ で大きく）
  - 大きさを変える（20〜200%）：右下の ◢ を引く。ホイールでも
  - 傾きを変える（−180〜180°）：上の ↻ を回す。0°・±90°・180° の近くでは吸い付く
  - もう 1 枚貼る：右上の ＋（回の付箋・資料のイラスト・しおりは 1 枚だけなので出さない。この 3 か所のシールも自由に動かせ、動かしたものは `moved: true` と位置を持つ。右の「元の位置に」で戻す）
  - はがす：左上の ×、または Delete
  - 重なり順を変える（前へ・後ろへ）・まっすぐに戻す：右の欄
- 位置は、貼った先の部品の大きさに対する割合（0〜1）で覚える。部品の大きさが変わっても、同じ場所に貼られたままになる。
- 貼る先ごとの基準：
  - フォルダ：カードの大きさ。
  - ホームの余白：ノートの紙全体（内容が長いと下へ伸びる）。
  - 授業ページの見出し：「← ホーム」と授業名の行。
  - PDF 編集画面の余白：ツールバーより下の窓。PDF をスクロール・拡大しても動かない。PDF の下に置くので、PDF に重なる所は隠れる。
- シールはいつも文字や PDF の下に置く（読みやすさのため。§4.6）。
- はじめから入っているシールの id は `builtin-…`。アプリの中で SVG を作るので、テンプレートの `assets` には入れない。

## 7. テンプレートの形式

ショップを開くときの土台になるので、第 1 弾から次の形で持つ。

```jsonc
{
  "format": "daigaku-note.skin",   // 種類（固定）
  "formatVersion": 1,              // 形式の版。読めない新しい版は「新しいアプリで読んでください」と断る
  "id": "01JB…",                   // 識別番号（ULID）。複製すると新しくなる
  "name": "ミント × ストライプ",
  "author": "大学ノート",          // 作った人
  "version": "1.0.0",              // 作った人が付ける版
  "license": "personal",           // 利用条件（下の表）
  "createdAt": "2026-10-21T00:00:00Z",
  "parts": {                       // 部品ごとの値。決まった名前と値の範囲だけを受け付ける
    "folder": {"card": "#fffdf6", "tab": "#f6c445"},
    "tape": {"color": "#7fd1ae", "pattern": "stripe"}
  },
  "stickers": [                    // どこに、どのシールを、どう貼るか
    {"place": "folder", "asset": "sha256-…", "x": 0.82, "y": 0.78, "scale": 0.6, "rotate": -12, "z": 1}
  ],
  "assets": {"sha256-…": {"mime": "image/png", "w": 256, "h": 256}}
}
```

| 利用条件 | 意味 |
|---|---|
| personal | 自分で使うだけ。配り直し・改変して配るのは不可 |
| share | 改変しないまま配ってよい |
| remix | 改変して配ってよい（作った人の名前を残す） |

**安全の決まり**
- テンプレートは**値だけ**を持ち、プログラムも CSS の文字列も持たない。
- 色は `#rrggbb` か `course`（授業の色。4.4）だけを受け付ける。柄や種類は、決まった名前の中から（テープの柄は `course` も）だけ選べる。`course`（授業の柄）は「クラシック」のためのもので、細かく直す画面の柄の選択肢には出さない。
- 知らない項目は読み飛ばす。値の範囲を外れたものは既定値にする。
- 画像は、取り込むたびに 6.1 と同じく描き直す。

**書き出し・読み込み（第 3 弾）**
- 1 つの JSON ファイル（拡張子 `.dnskin`）で書き出す。中身は上の形式に、取り込んだ画像を `assetsData`（SHA-256 → PNG の base64）として足したもの。
  はじめから入っているシールはアプリの中にあるので、ファイルには入れない。
- 読み込むと、画像を描き直して（付加情報を落とし、壊れた画像は弾き、長辺 512px に収める）シール帳に入れ、テンプレートの一覧に加える。
  描き直すと中身の SHA-256 が変わるので、テンプレートの中の画像の id も付け替える。画像が見つからないシールは捨てる。
- 同じ識別番号の自作テンプレートがあるときは、「置き換える／別のものとして加える／やめる」から選ぶ。
- ファイルは 20MB まで、画像は 60 個まで・1 つ 2MB まで。

## 8. ショップへの道（今回は作らない）

テンプレートやパックを第三者から買えるショップは、次の段階を踏む。前の段階で需要が確かめられてから、次へ進む。

| 段 | 内容 | 必要なもの |
|---|---|---|
| 1 | テンプレートのファイルの書き出し・読み込み（第 3 弾） | 7 の形式 |
| 2 | 公式の無料パックをアプリに同封する（「季節」「くすみカラー」「理系」など） | サーバーなし |
| 3 | 公式ショップ：自分で作ったパックだけを売る。パック販売と単体販売の両方 | 商品一覧と配信のサーバー、購入の記録とアカウント、決済（Stripe など）、特定商取引法の表示 |
| 4 | 第三者への開放：作り手が出品して売る | 作り手の登録と本人確認、出品前の審査（著作権・不適切な内容）、権利者の申し立て窓口、売上の分配（Stripe Connect など）、税の扱い（お店が売り手か仲介か） |

**決めておくこと**
- アプリ内の通貨やポイントは作らない（資金決済法の対象になりうるため）。円でそのつど払う形にする。
- Mac の App Store を通して配るようになったら、Apple のアプリ内課金の決まりに合わせて見直す。
- 3・4 に進む前に、法律と税を専門家に確かめる。

## 9. データの持ち方

| もの | 置き場 |
|---|---|
| テンプレート | 自作は新しい表 `skin_template`（id・7 の JSON・作成日時・更新日時）。はじめからあるものはアプリのコードの中（`src/shared/skin.js`。id は `builtin-…`） |
| 全体のテンプレート | 設定 `skin.global`（テンプレートの id） |
| 授業のテンプレート | `courses` に `skin_template_id`（空なら全体と同じ）と `sticker_mode`（global・course・both）を足す。今の `color`・`tape_pattern` は 4.4 の割り当てに使い、残しておく |
| シールの素 | 新しい表 `sticker`（id＝PNG の SHA-256・幅・高さ・形・フォルダ分け・お気に入り・取り込み日時）。画像はアプリのデータの場所の `stickers/<sha256>.png`（PNG だけなので mime は持たない） |
| 最近使った色 | 設定 `skin.recentColors` |

バックアップ（SPEC.md §12）には、テンプレートとシールの素も含める。

## 11. 決定事項

| 事項 | 決定 |
|---|---|
| 背景画像 | 入れない。フォルダの画像はシールだけ |
| 全体と授業ごと | 両方に対応。どちらもテンプレートから選ぶ |
| テンプレートを直したとき | つながる（使っている授業がみな変わる）。保存の前に使用中の数を知らせる |
| 右クリックの「着せ替え…」 | その場の選択パネルで、すぐ切り替える。下に「＋ 新しく作成」 |
| ダークモードの色 | 選んだ色を自動で暗くした色にする |
| シールを貼れる場所 | 5 の表の 8 か所 |
| 丸ドット | 中央がくり抜かれた輪のドット |
| ショップ | 8 の段階を踏む。今回は作らない |
| 先にやること | 文字隠しのずれの修正 |

**作りながら決める細部**：はじめからあるテンプレートの具体的な色の組み合わせ、ボタンのアイコン、ダークモードで暗くする計算の値。いずれも見本の画面を作って確かめてから決める。
